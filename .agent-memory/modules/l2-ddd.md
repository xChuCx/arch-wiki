## L2.DDD.02 Tactical DDD - Aggregates, Entities vs Value Objects, Domain Events invariants
<!-- @id: l2-ddd-02-tactical-ddd-aggregates-entities-vs-value-objects-doma -->
**Executive Summary:** **TL;DR**: *   **Value Objects** — это ваша главная защита от "Primitive Obsession". Используйте их везде, где нет жизненного цикла. *   **Entities** — нужны только там, где важна история изменений и идентичность. *   **Aggregates** — это **границы транзакций**, а не просто графы объектов. Главное правило практика: делайте агрегаты максимально мале
